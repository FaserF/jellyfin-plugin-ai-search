AI Search & Recommendation

Adds an AI search bar to the web client that recommends titles from your own library, and can add meaning-based matches to Jellyfin's own search. Set a language model and a retrieval source below for the search bar; the "Jellyfin search" section below only needs a retrieval source.

Repository & Automatic Updates
To keep this plugin up to date and resolve "Developer: Unknown / Repository: Unknown" in the dashboard, add this repository to Dashboard → Plugins → Repositories → + (Add):
https://raw.githubusercontent.com/FaserF/jellyfin-plugin-ai-search/main/manifest.json

1. Language model

The AI that reads your request and picks titles. Any OpenAI-compatible chat endpoint works (OmniRoute, OpenAI, Anthropic, Gemini, Ollama, OpenRouter, LiteLLM...), or a platform's /api/media/chat.

On: a model chooses the best matches from retrieval and writes a one-line reason for each. Off: the plugin returns the retrieval matches directly, ranked by relevance, with no reasons. Turning it off needs no chat endpoint, only a retrieval source below.
Select an AI provider. Selecting a preset auto-fills standard endpoint URLs.
The complete URL. Examples: http://omniroute:20128/v1/chat/completions, https://api.openai.com/v1/chat/completions, https://api.anthropic.com/v1/messages.
API key or bearer token. Leave blank if not required (e.g. internal OmniRoute or local Ollama).
Set the models endpoint below, then Reload models.
Lists available models for the dropdown, e.g. .../v1/models or .../api/media/models. Leave blank to just type the model id above.
A cheaper model for the short "Help me choose" questions. Blank reuses the model above.
Newer OpenAI models refuse max_tokens and want max_completion_tokens. Automatic handles that on the first request and remembers it.

2. Retrieval source

A service embeds your query and returns candidate titles from an index it maintains. Steps: (1) point Search endpoint at the service; (2) paste its API key; (3) make sure the service has indexed your library. Nothing is built or stored on this server.

Returns ranked candidates for a query (no model call), e.g. https://ai.example.com/api/media/search.

The plugin builds its own embedding index of your library on this server and queries it. Steps: (1) set an embeddings endpoint + model; (2) Save; (3) click "Build index now" (or wait for the nightly Scheduled Task "Build AI Search index"). Until it's built, a plain catalog slice is used as a fallback.

Enables the "TV Shows" scope. Episode counts can be large, so the first build after enabling this may run for a while. Rebuild the index after changing it.

3. Options

Ticked libraries are left out of the index, the AI search popup and the AI matches in Jellyfin's search. They still show up in Jellyfin's normal title search. Rebuild the index after changing this to free the space they took.
How many shortlisted titles the model chooses from (local index and remote search).
Caps how much of each candidate's synopsis is sent to the model. 0 sends the full synopsis.
Used by the AI search popup, the AI Search row and the reasons given for each result.

4. Jellyfin search & Third-Party Clients (Plezy, Mobile, TV)

Adds meaning-based matches and zero-hit recommendations to Jellyfin's search and third-party apps like Plezy, Findroid, and Swiftfin.

Recommended: Exact/contains movie and series searches return instantly without AI overhead. If 0 title matches exist, or when typing descriptive natural language sentences (e.g. in Plezy or Web), the AI engine automatically triggers and delivers smart recommendations.
Skips short keyword-style searches, where meaning-based matches tend to be noisy.
For apps other than the web client's AI Search row: Jellyfin shows search results only once every source has answered, so this caps how much a slow embedding or search backend can delay a search. A slower call still finishes in the background and is reused by the next search.
The row appears under Jellyfin's results and loads on its own, so title results never wait for it. Other apps (TV, mobile) get the matches mixed into Jellyfin's results instead.
Once a search settles, asks the chat model above for a one-line reason per result. Without it, each result shows which of your words it matched, and a synopsis excerpt.
Hides the AI search bar and its popup entirely, and turns off its endpoints. Jellyfin's own search still gets meaning-based matches from the option above (and the AI Search row, if on).

5. Search log

Records Jellyfin searches and AI popup searches to a local file, for an admin or API key to read.

The log is read by an admin or API key at GET /AiSearch/SearchLog.

6. Suggestarr & Media Requests

Integrates with Suggestarr and Jellyseerr / Overseerr. Automatically factors user ratings (from the K3ntas Ratings plugin, Plezy, or Jellyfin Web) into AI recommendations and triggers automated download suggestions.

When enabled, user ratings and AI recommendations feed into automated suggestions and downloads.
Examples: http://suggestarr:5000 or http://jellyseerr:5055.
API key from Suggestarr user profile or Jellyseerr Settings → General.
Triggers an automatic request/suggestion when a user rates an item with the minimum stars configured below.
Default: 4 stars (or 8/10 in the K3ntas Ratings plugin).
Suggestarr Feed Endpoint:
GET /AiSearch/Suggestarr/Feed?userId={userId}&minStars=4
Provides an official JSON list of user-favorited and highly rated candidates for Suggestarr automated import jobs.
